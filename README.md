# Плагины обучения

Репозиторий локальных плагинов Codex. Каталог находится в
`.agents/plugins/marketplace.json`, пакеты — в `plugins/`.

Сейчас в каталоге доступен `uptime-toolkit`. Его исходники уже находились в
этой папке до создания репозитория.

Чтобы проверить каталог локально:

```powershell
codex plugin marketplace add .
codex plugin list --marketplace uptime-marketplace --available --json
```

Для установки плагина используйте каталог плагинов в приложении Codex.

Путь `/Users/alaricode/plugins/`, упомянутый при создании репозитория,
относится к другой машине и здесь недоступен. Плагин из этого каталога можно
добавить после получения его файлов или точной ссылки на исходный репозиторий.
