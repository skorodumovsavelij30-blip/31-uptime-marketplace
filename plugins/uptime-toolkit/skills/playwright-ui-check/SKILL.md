# Проверка интерфейса через Playwright MCP

Применяйте этот навык после реализации изменений, которые затрагивают страницы, стили, клиентский код или пользовательские сценарии. Для всех действий в браузере используйте Playwright MCP.

1. Запустите приложение по инструкции в `README.md` или `AGENTS.md` и откройте нужную страницу через Playwright MCP.
2. Пройдите затронутый пользовательский сценарий реальными действиями в браузере. Проверьте ожидаемый результат и важные состояния, включая ошибки или валидацию, если они относятся к изменению.
3. Осмотрите верстку затронутых экранов в обычном и узком окне браузера. Проверьте читаемость, расположение элементов, переполнение и доступность основных действий. При необходимости сделайте скриншоты через Playwright MCP.
4. Проверьте ошибки в консоли браузера и неудачные сетевые запросы, относящиеся к сценарию. Исправьте найденные проблемы и повторите затронутую проверку.
5. В итоговом ответе укажите, какие страницы и действия проверены, что получилось, и какие проверки не удалось выполнить. Не называйте проверку успешной, если Playwright MCP не запускался или сценарий не был пройден.

Используйте подходящие тестовые данные; не меняйте реальные учетные записи или данные без разрешения. Если Playwright MCP недоступен либо приложение не удается запустить, зафиксируйте конкретную причину и сообщите о непроверенной части результата.
