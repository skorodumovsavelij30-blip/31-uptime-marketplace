# Uptime Toolkit

Локальный плагин `uptime-toolkit`, версия `0.1.0`, объединяет подготовленные
скиллы проекта:

| Скилл | Назначение |
| --- | --- |
| `golang-code-style` | Стиль и читаемость Go-кода |
| `vercel-react-best-practices` | Производительность React и Next.js |
| `playwright-ui-check` | Проверка верстки и сценариев через Playwright MCP |

## Локальная установка и проверка

Персональный каталог находится в
`C:\Users\YTS-Comp4\.agents\plugins\marketplace.json`.
Источник называется `uptime-personal`, отображаемое имя —
«Uptime — личные плагины».

1. Перезапустите Codex, откройте каталог плагинов и выберите этот источник.
2. Установите `Uptime Toolkit`.
3. Откройте новый чат в нужном проекте и явно попросите применить один из
   скиллов плагина.

Пример запроса:

> Используй golang-code-style из uptime-toolkit и проверь читаемость Go-кода проекта.

Для проверки регистрации через установленный Codex CLI:

```powershell
codex plugin marketplace list --json
codex plugin list --marketplace uptime-personal --available --json
```

В Codex CLI 0.160.1 также доступна установка:

```powershell
codex plugin add uptime-toolkit@uptime-personal
```

Плагин содержит скиллы и их справочные файлы. Для `playwright-ui-check` нужен
отдельно настроенный Playwright MCP в среде, где запускается проверка.
Упомянутые в этом скилле `README.md` и `AGENTS.md` относятся к проверяемому
приложению. При отсутствии MCP скилл должен явно сообщить, что браузерная
проверка не выполнена.

Исходные скиллы проекта также могут появляться в списке доступных скиллов.
Для проверки именно плагина укажите `uptime-toolkit` в запросе или выберите
его скилл в интерфейсе.

## Состав и обновление

Манифест: `.codex-plugin/plugin.json`. Скиллы: `skills/`.
Источники и изменения копий перечислены в [SOURCES.md](SOURCES.md).
Плагин использует поддерживаемый Codex-совместимый формат.

Это самостоятельные копии скиллов. Изменения исходников в `.agents/skills/`
не попадают сюда автоматически. После обновления файлов плагина перезапустите
Codex и проверьте установленную копию; если она осталась прежней, переустановите
плагин из личного каталога. Локально установленные плагины загружаются из
кэша Codex.

Копия персонального каталога для просмотра находится рядом с папкой плагина:
`../uptime-personal.marketplace.json`. Его `source.path` отсчитывается от
`C:\Users\YTS-Comp4`, а не от расположения этой копии или `.agents/plugins/`.
При переносе проекта обновите путь в действующем персональном каталоге.

Формат и порядок локального тестирования:
[официальная документация OpenAI](https://developers.openai.com/plugins/build/plugins).
